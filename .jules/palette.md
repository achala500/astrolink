## 2026-03-31 - Responsive Dock Icon Buttons Accessibility
**Learning:** Responsive UI components that hide text labels on smaller screens (e.g. `<span className="hidden md:inline">`) turn into icon-only buttons on mobile viewports. Relying on `title` attributes alone is insufficient for screen readers and mobile accessibility engines. Furthermore, high-contrast dark and OLED Crimson night modes require explicit `focus-visible` ring colors (`focus-visible:ring-emerald-500` / `focus-visible:ring-red-500` with `ring-offset`) so keyboard/switch navigation stays visible against `#000000` backgrounds.
**Action:** Always complement responsive text buttons with explicit `aria-label` and `aria-pressed` state attributes, and supply dual-mode `focus-visible` outline styles for both default dark and night crimson themes.
