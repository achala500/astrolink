## 2026-10-30 - Remove Hardcoded Master Private Key from Client Application
**Vulnerability:** A hardcoded 32-byte Ed25519 master private key (`_MASTER_PRIVATE_KEY_HEX`) was embedded directly in `backend/app/licensing.py`. In compiled desktop executables or deployed client code, reverse engineering could extract the signing key and forge arbitrary offline lifetime licenses, completely bypassing commercial licensing controls.
**Learning:** Utilities for key minting or testing are frequently placed alongside validation logic during development. When shipping client-side or offline binaries, private signing keys must never be bundled; only public verification keys belong in client-distributed binaries.
**Prevention:** Strictly enforce that signing keys are supplied exclusively via environment variables (`ASTROLINK_MASTER_PRIVATE_KEY`) or dedicated server-side tooling, raising immediate errors if missing, while bundling only the Ed25519 public key in application source code.
