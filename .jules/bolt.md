## 2026-11-08 - 2D Polynomial Surface Evaluation via 1D Broadcasting
**Learning:** Evaluating a 2D bivariate polynomial background surface on full-resolution astronomical images ($H \times W$) using full coordinate meshgrids (`np.mgrid`) and building an $(H \cdot W, K)$ feature matrix allocates hundreds of megabytes of temporary memory ($\approx 400\text{ MB}$ for 4K frames) and causes significant CPU cache thrashing during matrix-vector dot products, violating AstroLink's $<200\text{ MB}$ memory budget.
**Action:** When evaluating separable 2D polynomial surfaces across rectangular image grids, compute 1D coordinate vectors `x_1d` of shape `(1, W)` and `y_1d` of shape `(H, 1)`, and evaluate polynomial terms $x^i y^j$ using NumPy outer broadcasting. This reduces temporary memory allocation by $>90\%$ and speeds up surface generation by $>95\%$ with identical numerical results.
