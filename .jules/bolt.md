## 2026-03-30 - 2D Polynomial Evaluation Memory and Speed Optimization
**Learning:** Evaluating bivariate polynomials over 2D image grids by building full-resolution `(H*W, N_terms)` feature matrices creates massive RAM allocations (hundreds of MBs per image) and severe execution bottlenecks (~10s per 12MP channel). Because grid coordinates $x$ and $y$ are separable 1D sequences, evaluating term by term using 1D vector broadcasting `(x_1d**i)[None, :] * (y_1d**j)[:, None]` avoids `(H*W, N)` allocations completely, resulting in ~17.5x faster execution and 90%+ RAM reduction with floating-point exactness.
**Action:** When evaluating smooth analytical surfaces or 2D polynomials over dense regular grids, use 1D separable vector broadcasting or meshgrid term accumulators instead of dense flattened design matrices.
